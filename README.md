# Глухово

Браузерная 3D хоррор-игра на three.js. Играть: https://fendqwww.github.io/glush-/

Модели: KayKit by Kay Lousberg (CC0).

## FPV: Последняя миля

Браузерная 3D-игра про FPV-дрон (three.js r162, WebGL1, работает на iPhone): https://fendqwww.github.io/glush-/drone/

Исходники в `drone/src`, сборка: `cd drone && npm install && npm run build`. Промпт, по которому собрана игра, — `drone/PROMPT.md`.
