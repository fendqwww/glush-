# Промпт: «FPV: ПОСЛЕДНЯЯ МИЛЯ» — браузерная 3D-игра про FPV-дроны

> Этот промпт я (Claude) написал сам для себя перед началом работы. Игра собрана строго по нему.

## Роль

Ты — сеньор геймдев-инженер и технический художник, который пишет WebGL-игры на Three.js под мобильные браузеры. Ты не задаёшь вопросов, а принимаешь решения сам и доводишь игру до играбельного состояния за одну сессию.

## Цель

Сделать 3D-игру в браузере про FPV-дрон: игрок летит от первого лица через камеру дрона, залетает в дома через окна и двери, охотится на бронетехнику и машины, сбрасывает боеприпасы и таранит цели. Игра должна **запускаться и нормально играться на iPhone, включая старый Safari** (iOS 12–15), и на ПК.

## Жёсткие технические требования

1. **Совместимость.** Никаких ES-модулей и import map в рантайме: всё собирается esbuild в один IIFE-файл `game.js` с `--target=safari11`. Three.js версии **r162** — последняя, которая умеет WebGL1 (на iOS < 15 нет WebGL2). Никаких внешних CDN и ассетов: всё процедурное (геометрия, канвас-текстуры, звук через WebAudio). Игра лежит в подпапке `/drone/` репозитория `fendqwww/glush-`, хоррор-игру в корне не трогать.
2. **Производительность на телефоне.** Адаптивное разрешение рендера (держим ~50+ FPS, опускаем pixelRatio при просадке), объединение статической геометрии по материалам (BufferGeometryUtils.mergeGeometries), InstancedMesh для деревьев и мусора, пул частиц, одна направленная тень, которая ездит за дроном. Коллизии — через пространственную сетку AABB, а не через перебор.
3. **iOS-нюансы.** `viewport-fit=cover`, учёт safe-area, запрет зума и скролла (`touch-action:none`, preventDefault на touchmove), аудио разблокируется по первому тапу, кнопка «на весь экран» там, где API есть, подсказка «добавь на экран Домой», проверка поворота в landscape.

## Геймплей

### Физика дрона (главное!)
- Квадрокоптер как твёрдое тело: тяга вдоль локальной оси Y, гравитация, квадратичное сопротивление воздуха, инерция, угловые скорости по rates (как в Betaflight: RC rate, super rate, expo).
- Режимы полёта: **ACRO** (руками держишь угол, как настоящий FPV), **ANGLE** (стабилизация, стики = углы наклона, с автоподдержкой высоты на отпущенном газе — для новичков).
- Аплифт камеры (камера наклонена вверх на 15–35°), просадка батареи под нагрузкой, ground effect у земли, турбулентность от собственного потока у стен, prop wash при резком снижении.
- Столкновения: сфера дрона против AABB стен/крыш/техники, отскок с потерей энергии; сильный удар = поломка (для камикадзе = подрыв).

### Дроны (выбор в меню)
1. **Камикадзе 7"** — быстрый, несёт кумулятивный заряд, взрывается при ударе или по кнопке.
2. **Бомбер** — тяжёлый гекса/квадро, медленнее, 4 сброса (ВОГ), падающие по физике, с прицельной меткой точки падения.
3. **Оптоволокно** — не боится РЭБ, но тянет за собой видимый кабель и ограничен длиной катушки.
4. **Гоночный 5"** — без боевой части, максимальная тяга, для гонок и фристайла.

### Креатив
- **РЭБ** — зоны радиоэлектронной борьбы вокруг машин РЭБ: картинка рассыпается, появляются помехи, задержка и дрожь управления; можно потерять связь. Уничтожил РЭБ — в эфире чисто. Внутри домов сигнал тоже падает.
- **Аналоговый FPV-видеосигнал**: пост-обработка с бочкообразной дисторсией, хроматической аберрацией, шумом, строками развёртки, срывами кадра при слабом сигнале; OSD как в Betaflight (вольтаж, высота, скорость, RSSI, таймер, горизонт).
- **ПВО (зенитки)** стреляют трассерами по дрону, если видят его; прячься за домами.
- Слабые места техники: удар в крышу/корму наносит больше урона; горящие обломки дымят.

### Мир
- Процедурный посёлок/окраина города: дороги, перекрёстки, 1–3-этажные дома **с интерьером** (комнаты, лестничные проёмы, мебель-коробки), реальные проёмы окон и дверей, через которые можно пролететь; гаражи, ангар, заводской цех с широкими воротами, деревья, заборы, столбы с проводами, лес по краю карты, туман.
- Техника: танки (башня вращается на цель), БТР, грузовики, ЗСУ, машина РЭБ. Ездят по дорогам по маршрутам, у разрушенной — пожар и дым.

### Режимы
1. **Удар** — уничтожить все цели на карте ограниченным числом дронов.
2. **Конвой** — колонна проходит через посёлок, останови её до выезда.
3. **Гонка** — трасса из ворот, часть ворот внутри домов (влетел в окно — вылетел в дверь), лучшее время сохраняется.
4. **Оборона** — волны техники прут к твоей позиции, на каждую волну новые дроны.
5. **Свободный полёт** — без целей, фристайл и тренировка.

## Управление
- **Сенсор**: два виртуальных стика (Mode 2). Левый — газ (не центрируется по вертикали) и рыскание, правый — тангаж и крен. Кнопки: СБРОС/ПОДРЫВ, КАМЕРА (FPV / от третьего лица), РЕЖИМ (ACRO/ANGLE), ПАУЗА. Настройка чувствительности.
- **Клавиатура**: W/S газ, A/D рыскание, стрелки тангаж/крен, Space — сброс/подрыв, C — камера, F — режим, R — рестарт.
- **Геймпад** через Gamepad API.

## Графика (уделить максимум внимания)
- Физическое небо (шейдер градиента + солнце + дымка), туман, ACES-тонмаппинг, sRGB.
- Направленная тень высокого качества, следующая за дроном, hemisphere light для заливки.
- Процедурные текстуры на канвасе: кирпич, штукатурка, бетон, асфальт с разметкой, шифер/черепица, трава с шумом, земля, ржавый металл, камуфляж на технике. Нормал-карты из высоты.
- Взрывы: вспышка + точечный свет, огненный шар из спрайтов, дымовые столбы, разлетающиеся обломки с физикой, ударная волна, воронки-декали, тряска камеры.
- Пропеллеры вращаются, у дрона светодиоды, видимая модель в виде от третьего лица.
- Пост-эффект FPV-очков с настройкой (можно отключить).

## Звук (WebAudio, синтез)
Вой моторов с питчем от оборотов, ветер от скорости, взрывы, шипение помех, писк сброса, выстрелы зениток, «пип» при наборе таймера.

## Структура кода
```
drone/
  index.html        — разметка UI, стили, подключение game.js
  game.js           — сборка (esbuild IIFE, safari11)
  src/main.js       — цикл, состояние игры, меню
  src/input.js      — сенсор, клавиатура, геймпад
  src/drone.js      — модель и физика дрона
  src/world.js      — генерация мира и коллизии
  src/textures.js   — процедурные текстуры
  src/vehicles.js   — техника и ИИ
  src/fx.js         — частицы, взрывы, обломки
  src/post.js       — FPV-пост-обработка
  src/audio.js      — синтез звука
  src/modes.js      — режимы
```

## Критерии готовности
- Открывается по ссылке на iPhone (Safari), показывает меню, после тапа «Взлёт» дрон летает и управляется стиками.
- Во все режимы можно поиграть от начала до экрана результата.
- В дом можно залететь через окно и вылететь через дверь.
- Техника ездит, взрывается, горит.
- Нет ошибок в консоли; 60 FPS на ПК, 30+ на iPhone.
